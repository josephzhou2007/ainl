8 · 踩过的坑

(a) Chrome 138+ 不开「Allow User Scripts」，Tampermonkey 静默不运行
现象记录器装好了、图标也在，但一条事件都不记，无任何报错
根因Chrome 138 起扩展的用户脚本 API 需在扩展详情页单独打开「允许用户脚本」开关，未开时脚本注入被静默丢弃
怎么防装完立刻用菜单里的 stats 命令验证计数非零，把「计数 > 0」当作安装成功的唯一判据
(b) Chrome 弹窗拦截静默吃掉 McGraw Hill 的 LTI 启动，界面却说成功了
现象Canvas 点作业「跳转两次然后就没了」，页面没有任何错误提示
根因MH 的 LTI 1.3 链依赖两层 window.open 命名弹窗；被拦截后 form-post 落到一个不存在的窗口，connect.mheducation.com 在 3,864 个请求里一次都没出现（交互日志里 6 次 about:blank 就是被吞的弹窗）
怎么防判断成功与否只看最终落地域名（应到 /student/todo），不看 UI；对该站点为域名放行弹窗
(c) Anything Analyzer 的内嵌浏览器引导不起 Cengage 的 SPA（webpack 代码块 404）
现象对 gateway.cengage.com 零 POST——LTI 启动表单从未提交；只有 3 个 *.app.bundle.js 的 404，然后 302 弹回 Canvas
根因webpack 5 publicPath:'auto' 靠 document.currentScript.src 推算资源根路径；内嵌浏览器的脚本注入层让 currentScript 不可用 → 回退到 / → 实际部署在 /frontend/ → 404 → 启动脚本从未执行
怎么防换版本、清缓存都没用——问题在 JS 运行时环境不在网络层。内嵌浏览器不是这活儿的工具，用真实 Chrome。（同时作废了早前「analyzer 破坏 OAuth 签名」的结论）
(d) Google 禁止在内嵌 WebView 里登录
现象ESL116 的 Google Docs 模板作业三次都落到 accounts.google.com/v3/signin/rejected
根因Google 自 2016 年起明确拦截内嵌 WebView 的登录（"This browser or app may not be secure"），指纹怎么伪装都过不去
怎么防凡涉及 Google 登录的链路一律走真实浏览器，不要浪费时间调指纹
(e) 子代理在 worktree 里跑 pip install -e 会把可编辑安装指过去
现象子代理任务完成、worktree 删掉之后，主仓库的 python -m ainl… 找不到模块或跑的是旧代码
根因可编辑安装记录的是路径；在 worktree 里重装会把这条路径改到临时目录，worktree 一删就悬空
怎么防任务书里写死「不要运行 pip install」，测试靠 pyproject.toml 的 pythonpath=["src"] 直接跑 python -m pytest -q——这条已写进两份任务书的硬性约束
(f) Windows SetEnvironmentVariable(…,'User') 只影响新开的终端
现象设好了 API key，当前窗口里程序仍报「缺少 key」
根因用户级环境变量写进注册表，已存在的进程不会重读
怎么防设完开新窗口；CLI 的缺 key 报错里直接带上这句提示（提交 8a119e2 就是干这个的）
(g) Telegram 409 ＝ 两个 bot 实例共用一个 token
现象getUpdates 持续返回 409 Conflict，消息时有时无
根因同一 token 只允许一个长轮询消费者；调试时旧进程没退干净，或早报进程与 bot 进程同时在拉
怎么防启动前确认没有同名进程残留；409 直接当作「有另一个我在跑」来排查，不要往网络问题上想
(h) Canvas 会话约 13 小时后死亡——因为轮换后的 cookie 没落盘
现象早上还好好的，晚上早报任务开始 401 并要求重新登录
根因canvas_session 每个请求都被重签，而进程退出时没有把新值写回 storage_state.json，下次启动用的是越来越旧的那份（探针显示冻结副本本身能撑 10.3 h）
怎么防ApiSource.close() 把 httpx cookie jar 的轮换值合并回 storage_state（canvas/session.py 的 save_cookies，已有回归测试 test_save_cookies_persists_rotated_session）

9 · 边界与原则

① 代理只搬运学生自己做出来的东西，绝不生产或提交学生没做过的作业。
L3 可以讲解、出练习、主动问你哪里没懂，但不替你写计分作业的答案；L7 不提交你没做过的东西。 对 WebAssign / McGraw Hill 这类计分测评一律不代交（L7-B 刻意不做）——手写识别管线到 save()（Save Progress，不消耗次数）为止， 渲染结果截图回 Telegram 给学生确认，Submit 那一下永远由学生自己按。这条线一旦破了，这个项目就不可能交给学校。
② 凭证不进聊天，只走环境变量与本机文件。
不收集、不传输、不存储 NetID / 密码——UW 用 SSO + Duo，光有密码也登不进去；真出事责任落到个人头上。 所有 key 只从环境变量读（ANTHROPIC_API_KEY / GEMINI_API_KEY / DASHSCOPE_API_KEY / MATHPIX_* / TELEGRAM_BOT_TOKEN）， 缺 key 在构造时抛 ProviderNotConfigured 而不是 import 时；配置对象用 repr=False，日志和探针只记名字、长度与短哈希，永不记值。 浏览器会话 storage_state.json 按密码对待，只留在 ~/.ainl/。记录器只记 URL / 按钮文字 / 域名跳转 / 文件名，不记答案、成绩、表单值，且完全不联网。
